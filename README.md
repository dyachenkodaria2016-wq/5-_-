# Тренажер «Округлення десяткових дробів» (5 клас)

Автономний навчальний вебзастосунок українською мовою. Працює на звичайному HTML, CSS і JavaScript — без сервера, npm та складного складання проєкту.

## Файли проєкту

- `index.html` — сторінка, навчальні блоки та SVG-ілюстрації.
- `styles.css` — оформлення й адаптивність.
- `app.js` — генерація прикладів, перевірка відповідей, підказки та пояснення.
- `README.md` — ця інструкція.

## Запуск на комп'ютері

1. Завантажте всі чотири файли в одну папку.
2. Відкрийте `index.html` подвійним клацанням у браузері.
3. Для роботи тренажера підключення до сервера не потрібне. Шрифт Nunito завантажується з Google Fonts; якщо інтернету немає, використовується системний шрифт.

## Публікація на GitHub Pages

1. Увійдіть на [GitHub](https://github.com/) та натисніть **New repository**.
2. Введіть назву репозиторію, наприклад `rounding-decimals-5grade`. Для навчального проєкту можна обрати **Public**.
3. Створіть репозиторій кнопкою **Create repository**.
4. На сторінці репозиторію натисніть **Add file → Upload files**.
5. Перетягніть `index.html`, `styles.css`, `app.js` і `README.md` у головну папку репозиторію (не всередину додаткової папки).
6. Унизу сторінки натисніть **Commit changes**.
7. Відкрийте **Settings → Pages**.
8. У розділі **Build and deployment** у полі **Source** виберіть **Deploy from a branch**.
9. У полі **Branch** виберіть `main`, а в полі папки — `/(root)`. Натисніть **Save**.
10. Зачекайте хвилину-дві та оновіть сторінку **Settings → Pages**. Там з'явиться адреса опублікованого сайту.

Якщо у вашому репозиторії доступний лише варіант GitHub Actions, перевірте, що файли лежать у корені репозиторію, а для простого статичного сайту оберіть розгортання з гілки (`Deploy from a branch`), якщо цей пункт доступний.

## Як користуватися

1. Прочитайте короткі пояснення та розгляньте схеми.
2. Натисніть **Нове завдання**.
3. Уважно прочитайте, до якого розряду потрібно округлити число.
4. Натисніть на проміжок після цифри потрібного розряду, щоб позначити уявну межу. Позначку можна пересунути.
5. Оберіть один із двох варіантів відповіді.
6. Унизу прочитайте покрокове пояснення. Кнопка **Підказка** допоможе, якщо виникли труднощі.

Лічильник показує кількість перевірених завдань і поточну серію правильних відповідей поспіль.

## Примітка для вчителя

Застосунок генерує цілі та десяткові числа, зокрема приклади з переходом через дев'ятку (наприклад, `3,996`). Результати округлення формуються без похибок двійкової арифметики — через роботу з цифрами та цілими значеннями.
